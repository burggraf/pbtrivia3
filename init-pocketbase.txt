Create a bash script to initialize the pocketbase environment for local testing.  This should include:
1. creating an admin user:
`./pocketbase superuser upsert admin@example.com Password123`
2. running migrations
`./pocketbase migrate`
3. starting the pocketbase server (in the background)
`./pocketbase serve --dev --http 0.0.0.0:8090 &`
Also create a script to stop the pocketbase server.
Create a third script to reset the pocketbase environment, which should include stopping the server and resetting the database (removing ./pb_data, ./pb_migrations, ./pb_public, ./pb_hooks).
Finally, create a migration to create the questions collection and load it with data from the questions.tsv file.
